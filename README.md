# AI Resume Analyzer

An intelligent resume analysis app powered by ChatGPT‑4o, built with React and TailwindCSS.

It allows users to upload resumes and instantly receive AI‑driven insights on formatting, keyword relevance, and ATS compatibility.

The clean, responsive interface makes feedback easy to understand, helping job seekers refine their resumes and recruiters quickly identify strengths.

This project blends modern frontend design with advanced AI capabilities, creating a practical tool for professional growth and hiring efficiency.
